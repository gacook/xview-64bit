## Project Overview

This is XView 3.2 modernized for 64-bit Linux (AMD64). XView is the X Window System-based implementation of the OPEN LOOK GUI specification, originally from Sun Microsystems. The codebase adapts `xview-3.2p1.4-25.16` to work on modern Ubuntu/Debian with 64-bit architecture.

Libraries install to `/usr/openwin`. The build requires root for the install steps.

## Build System

The project uses **Imake** (X11R6 configuration system) with a custom wrapper. `Build-LinuxXView.bash.amd64` is the authoritative build script — it sets up the environment, generates `imake.append`, and orchestrates all build phases.

**Full build and install (requires sudo):**
```bash
sudo bash ./Build-LinuxXView.bash.amd64 all
```

**Individual build phases** (source the script first to set up environment variables):
```bash
source ./Build-LinuxXView.bash.amd64      # Set up environment (IMAKEAPPEND, IMAKEINCLUDE, PATH)

bash ./Build-LinuxXView.bash.amd64 libs          # Build libxview and libolgx
bash ./Build-LinuxXView.bash.amd64 instlibs      # Install libraries to /usr/openwin
bash ./Build-LinuxXView.bash.amd64 clients       # Build client applications
bash ./Build-LinuxXView.bash.amd64 contrib       # Build contrib examples
bash ./Build-LinuxXView.bash.amd64 olvwm         # Build Open Look Window Manager
bash ./Build-LinuxXView.bash.amd64 clean         # Clean all build artifacts
```

**After sourcing the environment**, standard make targets work:
```bash
make World          # Full rebuild from scratch (libs phase)
make Clients        # Build clients
make Contrib        # Build contrib
make depend         # Update dependencies
```

## Architecture

### Key Configuration Files
- `config/host.def` — Architecture definition (`AMD64Architecture`, debug flags). Edit this to change architecture or compiler flags.
- `config/XView.cf` — Feature configuration options (shared libs, locale, X11 version)
- `config/XView.tmpl` — Imake template with all build rules and variable definitions
- `config/XView.rules` — Library and program compilation rules
- `imake.append` — Generated by the build script; appended to every Makefile. Contains path overrides, `_FORTIFY_SOURCE=0`, and flag definitions. **Do not hand-edit** — it is regenerated by `Build-LinuxXView.bash.amd64`.

### Major Components
- `lib/libxview/` — Core GUI toolkit: widgets, panels, frames, menus, canvases, event handling
- `lib/libolgx/` — OLGX graphics library implementing OPEN LOOK visual specification
- `lib/pixrect/` — Pixrect compatibility layer (originally Sun pixrect API)
- `clients/` — XView applications: `cmdtool` (terminal), `clock`, `olwm`/`olvwm` (window managers), `props`, `textedit`
- `clients/olvwm-4.1/` — OLVWM window manager; has its own separate Imake invocation
- `contrib/examples/` — Example programs demonstrating XView API
- `build/include/` — Generated/staged headers (in-tree build output)

### 64-bit Adaptation Notes
These changes are what make XView work on modern 64-bit Linux — be careful not to regress them:
- `_FORTIFY_SOURCE` is explicitly disabled (`-U_FORTIFY_SOURCE -D_FORTIFY_SOURCE=0`) because glibc's buffer checks reject XView's internal window object buffers that are technically too small by modern heuristics but have worked for 30+ years.
- `-fno-stack-protector` is set for the same reason.
- `config/host.def` disables `i386Architecture` and enables `AMD64Architecture`.
- `-ltirpc` is included positionally *after* client objects (not as a leading flag) to avoid the linker marking it as unneeded before symbols are referenced.
- `-lncurses` is added as a misc library for clients that need it.
- `OPENWINHOME` is set to `/usr/openwin`.

## Dependencies

```bash
# Ubuntu/Debian
sudo apt install build-essential xutils-dev libx11-dev libxt-dev libxext-dev \
                 libboost-dev libtirpc-dev libncurses-dev imake
```

- C99-compliant compiler (variadic macros required)
- Boost.Preprocessor headers
- X11R6 development files
- libtirpc (for RPC headers in `clients/`)
- ncurses

## Testing

Run applications on your native window manager, or use olvwm in a nested X server:

```bash
# Start nested X server
Xephyr -screen 1920x1080 :1 &

# Start olvwm on nested display
/usr/openwin/bin/olvwm -f -display :1.0 &
```

Right-click the olvwm desktop to get the context menu; launch a Shell Tool from there, then run applications from that shell.
